# Portfolio Website

Phero Tube is a modern video-sharing website created to emulate the core functionalities of YouTube.

---

## Overview
Phero Tube is a video-sharing platform inspired by YouTube, designed to provide users with a seamless experience for browsing, watching, and managing videos. The platform features a clean interface, dynamic content loading, and interactive functionality, making it a user-friendly solution for video content enthusiasts.

---

## Technologies Used
- **JavaScript**: For adding interactivity and dynamic content management.
- **Tailwind CSS**: For efficient and modern styling.
- **DaisyUI**: For pre-built UI components.

---

## Features
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Project Showcase**: Cards displaying project names, images, and links to details.
- **Smooth Navigation**: Scrollable sections for a seamless browsing experience.
- **Interactive UI**: Engaging components with modern designs.
- **Live Links**: Direct access to live projects and repositories.

---

## Dependencies

- `tailwindcss`

- `daisyui`
